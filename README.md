# 🚜 EJOYW – Janniks Bauernhofspiel

> **Ein kleiner Bauernhof für einen großen Entdecker.**

EJOYW entstand im November 2026 aus einer Idee von **Jannik (fast 5 Jahre alt)**. Er wollte ein Bauernhofspiel, das so ist wie auf einem echten Hof: mit Tieren, Feldern und richtiger Landwirtschaft – aber ohne Fahrsimulationen.

Dieses Projekt ist für ihn. Und für alle Kinder, die gern wissen möchten, wo Eier, Milch, Wolle und Gemüse herkommen. 🐄🐔🐑🌱

## 🎮 Spielen

**[EJOYW im Browser öffnen](https://aurisch.github.io/bauernhof2026/)**

Am besten auf dem iPad in Safari oder auf einem Computer. Keine App-Installation notwendig.

## 🌾 Was gibt es zu entdecken?

- **Tiere versorgen:** Kuh, Schwein, Schaf, Huhn, Pferd und Ziege benötigen Futter, Wasser und einen sauberen Platz.
- **Produkte sammeln:** Eier von den Hennen, Milch von der Kuh und Wolle vom Schaf.
- **Felder bestellen:** Möhren, Frühkartoffeln und Salat anbauen, gießen und ernten. Frühkartoffeln brauchen hier neun Spielwochen.
- **Landmaschinen kennenlernen:** Der Traktor wird erklärt, aber nicht gefahren.
- **Im eigenen Tempo spielen:** Keine Punktejagd, Werbung, Käufe oder Niederlagen.

Die Spielzeiten und Erträge sind kindgerecht vereinfacht. Die Wolle kann zu Beginn einmal gesammelt werden; anschließend wird eine jährliche Schur simuliert. Erwachsene übernehmen in der Realität Melken und Scheren. Auch für echte Kühe gilt: Milch entsteht nach der Geburt eines Kalbs.

## 💾 Speichern

Der Bauernhof wird nach jeder Aktion automatisch im **lokalen Browser-Speicher** (localStorage) gesichert. **„Jetzt speichern“** bietet eine zusätzliche Bestätigung.

Wichtig: Der Speicher gehört zum jeweiligen Browser auf dem jeweiligen Gerät. Wer auf einem anderen iPad weiterspielen will, kann über **„Spielstand sichern oder auf ein anderes Gerät übertragen“** einen Sicherungscode kopieren und dort wiederherstellen.

Private Browserfenster, das Löschen von Website-Daten oder ein Gerätewechsel ohne Sicherung können den Spielstand löschen. Es gibt keine Cloud-Synchronisierung und keinen zentralen Server.

## 🛠️ Technisches

- Statische Anwendung in einer einzigen `index.html` (HTML, CSS, Vanilla JavaScript)
- Ohne Framework, externe Abhängigkeiten, Cookies, Tracking oder Benutzerkonto
- Touch-Bedienung, responsive Gestaltung und optionale Sprachausgabe (Web Speech API, abhängig vom Browser)
- Quellcode offen einsehbar; Veröffentlichung über GitHub Pages
- Fortschritt über `localStorage`; Sicherung über JSON-Text

## 🌍 Veröffentlichung mit GitHub Pages

Das Repository ist öffentlich. Um die Spieladresse freizuschalten:

1. **Settings → Pages** im Repository öffnen.
2. Unter **Build and deployment** als Source **Deploy from a branch** wählen.
3. **main** und **/(root)** auswählen und speichern.
4. Anschließend die Spieladresse oben öffnen. Die Bereitstellung kann einen Moment dauern.
